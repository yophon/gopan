# 28 · 备选功能

> 活的清单:想过、还没定要不要做的功能,以及明确不做的。定下来要做的另开计划文档,做完从这里移走;不做的写清原因,免得反复提。

## 一、备选(还没定)

按日常用得多、改动小的顺序。

| 功能 | 范围 | 大概多大 | 说明 |
|---|---|---|---|
| 视频画中画 | 安卓 | 小~中 | 看视频时回桌面缩成小窗接着放;现在后台只能放音频 |
| 家人之间共享文件夹 | 全部 | 大 | 把一个文件夹共享给站内另一个账号,对方网盘里直接看到,可设只读 / 可改。前提是家里确实几个人各用各的账号 |
| 图片、扫描件里的字也能搜(OCR) | 服务端 | 中 | 内容搜索现在搜不到截图、扫描版 PDF 里的字。要在镜像里加识别引擎(大几十 MB),识别吃 CPU,服务器只有 2 GB 内存;做的话默认关、站点自己开 |
| 桌面端「gopan 盘」 | 桌面端 | 大 | 资源管理器里多一个盘(Windows Cloud Files API),文件按需下载,像 OneDrive |
| 投屏到电视 | 安卓 | 中 | 视频、音乐、图片推到同一个 Wi-Fi 下的电视或盒子(DLNA),手机当遥控器;电视直接从服务器拉流。外挂字幕大多数电视不认 |
| 电子书阅读(EPUB) | 网页 + 安卓 | 中 | .epub 直接翻着看,记住读到哪,换设备接着读(和 PDF 的「接着看」一样) |

视频画中画、家人共享文件夹、OCR、gopan 盘:2026-10-26 又讨论过一次,眼下觉得意义不大,先放着。

投屏到电视、电子书阅读:2026-10-26 提过,先放着。

## 二、往后再议

- **扫码登录网页**:想过的做法是网页登录页的二维码其实是一个链接,手机自带相机或浏览器扫了用 App Link 直接打开 App 里的「确认登录这台电脑?」,点确认网页就登进去;App 不用自带扫码库,安装包几乎不变大(内置 ML Kit 约 +2.4 MB,ZXing + 相机库约 +0.5~1 MB)。微信扫会在微信里打开网页、跳不进 App。安卓的按需功能模块要靠 Google Play 分发,自己发 APK 用不了,所以不做成插件。

- **助手的定时任务**:「每天早上把『下载』按类型归档」「每周一汇总上周的发票」这类,写一句要做的事 + 什么时候跑,结果进对话记录并发通知。依赖助手能在服务器上运行(doc/34),那个做稳之后再说。

## 三、不做

- **手机相册自动备份**:没有意义,不做。
- **App 锁**(指纹 / 面容 / 锁屏密码):不需要。
- **离线可用的同步、按收藏自动离线**:离线可用只是手动选的副本,手动更新(doc/26)。
