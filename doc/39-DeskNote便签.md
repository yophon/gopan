# 39 · DeskNote 便签

> DeskNote 是一个 Windows 桌面便签(github.com/yophon/desknote),每张便签存成一个 json,通过 MCP 同步到 gopan 的一个文件夹(默认 `/DeskNote`)。这里让网页和安卓 App 认出这些文件,画成清单,出门在手机上也能勾、能加;改动写回同一个文件,桌面端几分钟内拉到。服务端不加接口:读写用在线编辑(doc/25)的 `textFile` / `saveTextFile(baseSha256)`。

## 一、用的人看到的

- **打开便签文件就是清单**:在 `/DeskNote` 里点开一张便签(或者任何长得像便签的 `.json`),预览里不再是一屏 json,而是一张和桌面上同色的卡片:标题、带勾选框的条目、提醒标签(到点的变红)、条目里的链接能点。
- **直接改**:点勾选框勾掉;点一条的文字改它(清空 = 删掉);删除按钮;底部输入框添加一条;点标题改标题。每一步立刻生效、自动保存,右上角一行小字「保存中… / 已同步」。
- **看原文**:网页顶栏「原文 / 清单」切换,原文那边照旧能「编辑」;App 上顶栏的编辑按钮还是改原文。
- **两边同时改不打架**:桌面端在你打开之后改过这个文件,网页 / App 存的时候不会盖掉它(见二)。
- **回到页面时拉一次**:手机上切回浏览器 / App,清单重新读一次,桌面端刚改的能看到。

## 二、怎么接

### 认出便签

- 文件名以 `.json` 结尾,内容是对象、有字符串 `title` 和 `items` 数组、每条有字符串 `text`。不看所在文件夹:便签被挪到别处也认得。
- 网页:`PreviewModal` 本来就会把 TEXT 文件的内容拉下来显示,拉完判断一下;认出来以后保存时内容会重新拉,这期间不把清单拆掉(按节点 id 记住「这是便签」)。访客(分享页)不认,照旧显示原文。
- App:预览页 TEXT 分支读完内容后判断,是便签就换成 `PreviewContent.DeskNote`。离线副本(`file:` 地址)照旧显示原文——清单要联网读写。

### 写回

- 打开时读 `textFile`,记下内容和 sha256。每一步操作(勾选、改字、删、加、改标题)先改显示的内容,再排队一步步存:`saveTextFile(content, baseSha256)`,后一步基于前一步存完的内容。
- 存的时候报 `EDIT_CONFLICT`(桌面端在这期间改过):重新读最新内容,把这一步在它上面**重放**再存,最多三次。重放靠「操作时看到的文字」找回同一条:先看原位置是不是它,不是就按文字找第一条;找不到(那一条在桌面端被改了或删了)就放弃这一步,显示换成最新内容并提示。
- 只动 `title` 和 `items`,其余字段(`style` 和以后桌面端加的)原样留着;条目上的 `remind`、`reminded` 等也留着。写出的是两格缩进的 json,桌面端都认。
- 桌面端那边:每 5 分钟拉一次远端,内容变了就换成远端的;它自己两边都改了时会另存一张「冲突副本」,不丢。
- 网页与 App 各有一份同样的实现:`web/src/utils/desknote.ts`(`createDeskNoteSync`)、`android/…/core/data/desknote/DeskNotes.kt`(`DeskNoteSync`),都有单测(重放、放弃、排队)。

### 显示

- 卡片底色、字色用便签自己的 `style.bgColor` / `style.textColor`(没有就用桌面端默认的 `#34424D` / `#A9B1B7`);`style.checkboxes` 为 false 时不画勾选框,只画圆点。
- 提醒的说法和桌面端一致:今天「15:00」、明天「明天 15:00」、其余「11月21日 15:00」,跨年带年份。到点的规则也一样:`reminded` 且没做完。
- 链接的规则和桌面端一致:`http(s)://` 或 `www.` 开头,到空白或中文标点为止,去掉结尾的英文标点。

## 三、不做的

- 新建便签、删除整张便签、改颜色和窗口设置:这些在桌面上做;网盘里删掉文件桌面端也会跟着删(进回收站)。
- 设置 / 改提醒时间:只显示。提醒由桌面端到点弹通知。
- 拖动排序:手机上不好操作,先不做。

## 四、顺带:MCP 调用记录只留 90 天

- 每次 MCP 调用在 `mcp_audit` 记一条,之前从不清理。DeskNote 这种定时同步的客户端每 5 分钟拉一次,一天三四百条,一年十几万条。
- worker 加每天一次的 `mcp-audit-cleanup`:删 90 天前的,分批(每批 1 万条,一次最多 20 批),删不完第二天接着删。「Agent 接入」的操作记录页写上「只保留最近 90 天的记录」。

## 五、实时:不再等 5 分钟

3.25.0 时桌面端每 5 分钟拉一次,网页 / App 上开着的清单要切回页面才重读,用起来不够实时。3.25.1 改成推送:

- **推送接口收 MCP 密钥**:`GET /api/events`(doc/32 二)原来只认登录凭证;现在 `gopan_key_` / `gopan_mcp_` 开头的 API Key 也能连,要有 `files:read`。Key 可能只能访问某个文件夹,所以只转发文件改动(`files` / `resync`),而且去掉文件夹 id,只发 `{"t":"files"}`,客户端自己去读它能访问的那部分。其余照旧:每 5 分钟断一次重连、25 秒心跳、每人最多 16 条连接。
- **DeskNote**:后台线程连着推送,收到一条就 0.3 秒后同步一次(连着来的几条合成一次);刚连上也同步一次,补断开期间漏的。断了 3 秒后重连,连不上的退避到最长 2 分钟;老服务端不收密钥(401)时 5 分钟后再试。连着推送时定时拉取放慢到 30 分钟,只当兜底,审计日志也少了。本地改动推上去的防抖从 4 秒缩到 1.5 秒。
- **网页 / App 的清单**:本来就连着推送;收到「便签所在的文件夹变了」(或 `resync`)就重读。正在改字、还有没存完的操作时先记着,改完再读。自己刚存的也会推回来,重读一次内容不变。
- 延迟:电脑上改 → 1.5～2.5 秒推上去 → 网页 / App 收到推送立刻重读;手机上改 → 立即存 → 电脑上约 0.3 秒后开始同步。

## 七、提醒推到手机(3.26.0)

电脑上的 DeskNote 到点只能在电脑上弹通知;电脑关着、人不在电脑前就错过了。现在服务器也看提醒,到点走通知系统(doc/22)推到手机。

### 用的人看到的

- 到点收到一条「提醒 · 便签标题」,正文是那一条的文字;点开就是那张便签的清单。走「推送设置」里的渠道(ntfy / Bark / Telegram / Webhook),站内铃铛里也有。迁移把这类事件加进了已有的渠道,不想要就去掉。
- 网页和 App 的清单里能设置、修改、移除提醒,也能选重复(每天 / 工作日 / 每周)。重复的标签写规律(「每周四 09:00」),不变红。
- 电脑开着时电脑和手机都会提醒;电脑关着时手机照样收到,重复的也每次都收到。

### 怎么做的

- 便签条目多一个字段 `repeat`:`daily` / `weekdays` / `weekly`(DeskNote 2.1 起)。到点后桌面端把它顺延到下一次、勾掉的重新打开,不置 `reminded`;不重复的照旧置 `reminded`。网页、App 写回时只改 `remind`、`reminded`、`repeat` 这三个。
- 服务端 `DeskNoteReminders`(worker 每分钟一轮,`desknote-reminders`):
  1. **先推**:`desknote_reminders` 里到点、这一次还没推过(`fired_at < remind_at`)的,文件不在回收站就推;重复的推完由服务器算下一次(和桌面端同一个规则),电脑关着也接着推。晚了一天以上的不推(第一次扫到很旧的便签)。
  2. **再扫**:上次以来改过的 `.json` 文件(`desknote_scan` 记扫到哪了),认出是便签(规则同第二节)就把要提醒的条目写进表:不重复的要没提醒过、没做完;重复的都要。按条目文字认同一条(桌面端合并也按文字),同一次保留 `fired_at`,不重复推;服务器已经顺延过、桌面端还没跟上时,留着服务器算的那一次。
  - 先推后扫:电脑开着时,到点桌面端会先把条目标成已提醒(或顺延)并同步上来;先扫的话这一次就被跳过,手机收不到。
- 便签里的时间是本地时间,按服务器的 `GOPAN_TZ` 解释。
- 迁移 00034:`desknote_reminders`、`desknote_scan`,并给已有的推送渠道加上 `note_reminder`。

### 测试

- `TestParseDeskNoteReminders`、`TestNextRepeat`(纯函数);`TestDeskNoteReminders`(要 `TEST_DB_URL`,文件内容由测试给,不要对象存储):到点推、同一次不重复、已提醒的不推、电脑开着时先推后扫、电脑关着第二天照推并顺延、回收站里的不推、不是便签的 json 不记。
- 网页 `desknote.test.ts`、App `DeskNotesTest`:设提醒 / 移除提醒其余字段原样,重复的说法和「不算到点」。
