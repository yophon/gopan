# 11 · 使用手册

写给 gopan 实例的使用者。部署与运维看 doc/09,这里只讲"怎么用"。

## 登录与注册

浏览器打开站点地址即到登录页。实例是否开放注册由管理员决定(`GOPAN_REGISTER_OPEN`);私人实例通常关闭注册,需要账号找管理员建。

登录后凭据自动续期,正常使用不会被打断;两周不来才需要重新登录。**改密码会把该账号所有已登录的设备全部踢下线**,怀疑账号泄露时改密码即可止损。

## 界面总览

左侧导航:

| 入口 | 干什么 |
|---|---|
| 我的文件 | 目录树主界面,文件操作都在这 |
| 传输助手 | 电脑和手机之间互发文字、文件 |
| 我的分享 | 分享链接、收集链接、直链与图床 |
| 订阅 | RSS / 播客 / GitHub Releases,有新内容自动下进网盘 |
| 剪藏 | 存下来的网页文章,点开就是阅读视图 |
| 动态 | 谁在什么时候改了网盘里的什么,能撤回 |
| 回收站 | 删掉的东西在这躺 30 天 |

顶部是搜索框(按 `/` 或 Ctrl+K 直接跳过去)和通知铃铛;侧栏底部是用量条(已用 / 总额),点「空间分析」看空间花在哪;右下角是上传与后台任务的抽屉,有任务时自动出现。侧栏的「安卓 App · 更新日志」打开发布页(见下文「安卓 App」)。

最底下点自己的名字是账户菜单:**外观**(跟随系统 / 浅色 / 深色)、登录设备、WebDAV 应用密码、Agent 接入、修改密码、退出登录。

## 文件管理

- **选中与打开**:单击一行选中它,Ctrl(Mac 上 ⌘)点加选,Shift 点连选,也可以点行首的圆圈;点文件名或双击打开(文件夹进去、文件预览)。选中了东西,工具栏就换成下载、分享、移动、复制、重命名、删除。
- **右键**:条目上右键是它的全部操作(多选时对整组);空白处右键能上传、新建文件夹、全选、刷新。行尾悬停时也有下载、分享和「⋯」。
- **拖动**:把文件拖到某个文件夹上就是移动过去,拖到上面的路径(比如「我的文件」)就是移回上级;把电脑里的文件拖到某个文件夹上,就传进那个文件夹。
- **键盘**:Delete 删除、F2 重命名、Enter 打开、Ctrl+A 全选、Esc 取消选择、↑↓ 换选中、Backspace 回上一级。
- **列表 / 网格**:工具栏右边切换,网格看图片更直观;旁边是排序。
- **移动 / 复制到…**:对话框从当前文件夹开始,一层层点进去选目标,没有合适的可以就地新建文件夹。
- **同名冲突**不用管:上传或复制遇到重名,系统自动改成 `xxx (1).ext`。
- **复制是占配额的**:复制 1GB 文件,配额多扣 1GB(物理上不会真复制一份,但额度按逻辑算)。
- **移动**不能把文件夹移进它自己或它的子孙里,系统会拦。
- 排序:点表头或工具栏的排序按钮,按名称/大小/时间排(会记住),文件夹恒排在文件前。按名称是自然顺序:「第2集」排在「第10集」前面,英文在前、不分大小写,中文在后按拼音。
- **文件夹显示体积**:大小列直接显示整个文件夹占多少空间、多少个文件(悬停可见)。刚上传/删除完显示"约 X"是统计在后台刷新,一分钟内变准。

## 上传

几种方式:工具栏「上传」(旁边的箭头里有「上传文件夹」,目录结构原样保留)、把文件或文件夹拖进页面任意位置、拖到某个文件夹上直接传进去。单次拖拽最多 1000 个文件,超出的忽略并提示。

上传队列抽屉里每个任务可以**暂停、恢复、取消**,失败自动重试三次。几个行为说明:

- **有的文件瞬间完成**:这是秒传——服务器上已存在内容完全相同的文件(按内容哈希判断,与文件名无关),不需要重新传输,直接建立引用。秒传同样占你的配额。
- **断点续传**:上传大文件中途断网、关页面都没关系,重新上传**同一个文件**(内容没改过)会从断点接着传,已传完的分片不重传。
- **"服务端校验失败"**:上传完成后服务器会异步复核文件内容的哈希,极少数情况(传输损坏)会校验失败并回收该文件,重新上传即可。
- 上传中的文件自己立即可见可用,但要等服务端校验通过后,别人传同一文件才会触发秒传。

## 下载

- **单文件**:行内下载按钮或右键菜单。下载走对象存储直连,支持浏览器断点续传。
- **文件夹 / 多选**:打包成 zip 下载,**单次打包上限 2GB**,超了分批下。zip 只打包不压缩(照片视频本就压不动),打包速度接近下载速度。
- 下载链接是临时签名(15 分钟有效),不要把链接当分享用——分享走分享功能。

## 离线下载

手上只有一个下载链接、不想先下到电脑再传上来时,让服务器自己去下:文件页工具栏「离线下载」(手机上是链条图标),粘贴链接(一行一个,一次最多 10 条),点「开始下载」。文件会下到**当前文件夹**,进度在右下角「传输」的「后台任务」里,关掉页面也会接着下。

- 文件名优先用网站给的名字,其次是链接最后一段;和已有文件重名时自动改名。
- 下载中途断线会自动接着下(网站支持的话);失败的可以点「重试」,也能随时取消。
- **下不了的**:网盘分享页(百度、阿里云盘等)、需要登录的链接、BT / 磁力;内网和本机地址一律拒绝。下完提示「拿到的是网页,不是文件」时,多半是网站要求登录或拦截了服务器。
- 在安卓 App 里,从浏览器把链接「分享」给 gopan,传输助手的输入框上方会出现「离线下载这个链接」,下完自动出现在会话里。
- 离线下载占你的配额;站点可能为了省带宽限了速。

## 预览

点文件名直接预览,支持:

| 类型 | 效果 |
|---|---|
| 图片 | 列表有缩略图;预览大图支持缩放、旋转、翻页 |
| 视频 / 音频 | 浏览器原生格式(mp4/mp3 等)直接流式播放,视频有封面和时长;mkv / avi 这类浏览器放不了的会提示下载或用安卓 App 看(见下节「影音」) |
| PDF | 页内直接渲染 |
| 文本 / 代码 | 1MB 以内直接显示 |
| Markdown(.md) | 2MB 以内直接渲染成排好版的文章(表格、任务列表、代码块都有),同文件夹里用相对路径引用的图片也能显示;右上角「源文件」切回纯文本。剪藏下来的文章上方多一条来源(站点、原网页、标为已读) |
| Office(docx/xlsx/pptx) | 首次预览会触发转换(转成 PDF),等几秒到几十秒;之后秒开 |
| 压缩包(zip/7z/rar/tar.gz 等) | 不下载就看目录,预览里面的图片 / PDF / 文本,勾选解压,见下节 |

两个说明:

- 缩略图偶尔"裂开":刚上传完,预览图还在后台生成,刷新一下就有。
- Office 预览提示"本站未开启":精简部署的实例没有装转换组件(省内存),下载后本地看;图片/视频/PDF/文本预览不受影响。

## 影音

- **外挂字幕**:视频旁边放同名的字幕文件就会自动挂上——`电影.mp4` 配 `电影.srt`,或者带语言标记的 `电影.zh.srt`、`电影.chs.ass`、`电影.en.vtt`;文件夹里只有一个视频时,名字对不上的字幕也算它的。GBK 编码的老字幕正常显示;ASS 只保留文字,样式和特效不显示。有多条时右上角「字幕」里切换,默认选中文。安卓 App 还能选 mkv 里自带的字幕轨。
- **接着看**:5 分钟以上的视频、音频和 3 页以上的 PDF 会记住看到哪,换一台设备打开也从那里接着放(提示「从 23:15 继续 · 从头播放」);看到最后、翻到最后一页就算看完,下次从头开始。侧栏「最近播放」里是没看完的,× 可以去掉。分享访客不记。
- **连着放**:视频播完会倒计时 5 秒进下一集(同文件夹里按「第2集在第10集前面」的顺序),点「取消」就停下。点开一首歌,整个文件夹排进播放队列;关掉预览后页面底部留一条播放条,切页面不中断,能上一首 / 下一首、顺序 / 单曲循环 / 随机。手机浏览器锁屏、电脑键盘的媒体键都能控制;手机浏览器切到后台可能会被系统暂停,要稳定后台播放用安卓 App。

## 压缩包

点开 zip、7z、rar、tar(含 .tar.gz / .tgz / .tar.bz2 / .tar.xz)就进入包内浏览:点文件夹进去,点图片、PDF、文本直接看,其他文件可以单独下载。Windows 上打的 zip 里的中文名正常显示。刚传上来的包要等几秒读目录。

- **解压**:「全部解压」(或进了某个目录后「解压此目录」、勾选后「解压选中的 N 项」)会在压缩包旁边新建一个以包名命名的文件夹,解压到里面;「解压到…」换个位置。已有同名文件夹时新文件夹自动改名,**不会覆盖或合并已有文件**。右键 / 长按压缩包也能直接「解压到这里」。
- 解压在后台进行,进度在「传输」的「后台任务」里;解出来的文件占配额,和网盘里已有的相同内容不重复占空间。
- **看得到但打不开的**:加密的文件(文件名也加密的连目录都看不到)、路径带 `..` 的、链接,解压时跳过并计数;单个文件超过 100 MB,或在固实包里太靠后,不能直接预览,解压后再看;7z / rar 的压缩字典超过 64 MB 的整个包都不支持,请下载后解压。分卷压缩(.part1.rar、.7z.001)不支持。
- 分享出去的压缩包,访客也能浏览和预览里面的文件,但不能解压。

## 分享

文件、文件夹都能分享。选中后点"分享":

- **密码**:可选。设了密码,访客要输对才能看。
- **有效期**:按天设,0 或不设 = 永久;到期链接自动失效。
- 生成的短链接直接发出去即可。发进 Telegram 这类聊天会出卡片预览:名字、类型与大小(文件夹是文件数和体积)、几天后过期,单张图片和视频还带缩略图。**设了密码的分享卡片上不露名字**,只写「有人给你分享了一个文件」。

**访客看到什么**:打开就是一张写着名字、大小、过期时间的卡片。单个图片、视频、音频直接在页面里看 / 放,PDF、文档点「预览」;文件夹能浏览整个子树(大多是照片时默认用网格)、预览、下载单个、多选下载、整个打包——但**只读**,不能改不能删,也看不到分享范围以外的任何东西。页面跟着访客自己手机的深浅色走。访客授权 30 分钟,过期自动重新验证(有密码的要重输)。

**管理**:「我的分享」里能看全部分享和它们的状态,**吊销立即生效**——已经打开页面的访客,下一次操作就会被拒。

**访问记录**:每条分享都带访问次数,点开是最近 50 条明细(时间 / 动作 / IP / 客户端)。三个口径要留意:

- 只保留**最近 180 天**的记录,所以数字是"近 180 天",不是历史总量。
- "下载"统计的是**发起下载**的次数——文件字节由浏览器直连对象存储,服务端看不到传完的时刻。
- 分享链接被微信/群聊抓取生成卡片**不计入**访问(那是爬虫,不是人)。

## 直链与图床

**直链**是一个文件的永久公开地址(`https://<域名>/x/…/文件名`),适合贴进博客、论坛、Markdown 文档:图片、视频、PDF 直接显示,其他文件点开就下载。文件上**右键 → 复制直链**(手机上长按或点「⋯」),可选纯链接、Markdown、HTML;同一个文件重复复制拿到的是同一条。文件改名、被覆盖后地址照样能用;进回收站期间打不开,还原后恢复。

「我的分享」的 **直链** 标签里能看到所有直链:今天和近 30 天被访问了几次、多少流量;点开是 7 天按小时的图、来源站点排行、访问明细(时间、IP、客户端、来源),以及设置:

- **来源白名单**:只允许列出的站点引用(写 `example.com` 包括它的子域),可选是否允许直接打开;不设就用「默认规则」。不在名单里的引用会被拒,也计入「拦下」。
- **每天流量上限**:默认 5 GB,超了当天暂停、第二天自动恢复,并发通知提醒你。
- **有效期**、**异常时自动暂停**(访问量突然暴涨时直接停掉,默认只提醒);随时可以**暂停**或**吊销**,立即生效。
- 公开出去就是任何人都能看。照片里带拍摄位置时,复制直链会提醒一句。

**图床**:「直链」标签里直接粘贴截图(Ctrl+V)或拖入图片,会传进图床文件夹(默认 `/图床/年-月/`)并复制好 Markdown。用 PicGo、ShareX、uPic、Typora 写博客的话,在「上传接口」里建一把**图床密钥**,照页面上给的模板填进工具:它只能往图床文件夹传图片、拿直链,看不到你网盘里的其他东西;泄露了在这里吊销。图床上传默认抹掉照片里的 GPS 位置(「默认规则」里可关),单张不超过 20 MB。

## 通知

侧栏(手机上是顶栏)的铃铛是站内通知,红点是未读数:收集链接收到文件、离线下载或解压完成 / 失败、空间快满、每次有新的登录、新建了应用密码 / API Key / 图床密钥、直链被盗刷或用完流量;管理员还会收到备份失败的提醒。点一条直接跳到相关的地方。同一件事短时间内反复发生(比如收集链接一下收到 20 个文件)合成一条,标「×20」。

想在手机上第一时间知道,点抽屉右上角**推送设置**加一个渠道:

| 渠道 | 怎么配 |
|---|---|
| ntfy(推荐,安卓 / iPhone 都有 App) | 手机装 ntfy,订阅一个别人猜不到的 topic(如 `gopan-随机串`);这里填同一个 topic,服务器默认 `https://ntfy.sh` |
| Bark(iPhone) | 填 Bark App 里的 device key |
| Telegram | 用 @BotFather 建个 bot,填 bot token 和你的 chat id |
| Webhook | 填一个地址,gopan 会 POST 一段 JSON 过去;填了密钥会带 `X-Gopan-Signature` 签名 |

每个渠道可以勾选推哪些事件,点「测试」立刻发一条看看通不通。每个渠道每小时最多推 20 条,失败会重试 3 次,渠道上显示最近一次失败的原因。

## 动态与撤回

侧栏「动态」按时间列出网盘里的每一次改动:新建文件夹、上传、覆盖、改名、移动、复制、删除、还原、彻底删除、解压。每条写着是谁做的——哪台设备(「Edge · Windows」「安卓 App · Pixel」)、哪把 WebDAV 应用密码、哪个 Agent、哪条收集链接(带访客留的名字)、离线下载 / 解压 / 订阅 / 剪藏哪个后台任务——以及文件在哪、从哪移到哪、从什么名字改成什么名字。同一次操作(一次多选移动 50 个文件、Agent 的一次调用、一次解压)合成一组,可以展开。上面能按来源、操作和时间(今天 / 7 天 / 30 天)筛。文件右键「详情与历史」能看这一个文件的所有改动。

**撤回**:

- 移动 → 移回原来的文件夹(原位置有同名的,自动改名成「xxx (撤回 1022-1530)」);改名 → 改回原名;删除 → 从回收站还原;新建、上传、复制、解压、离线下载、剪藏 → 移进回收站;还原 → 再删进回收站。
- **覆盖和彻底删除撤不回**(没有历史版本),列表上的撤回按钮是灰的。
- 每条右边「撤回」;一组的「撤回这一组」;筛了某个来源时上面有「全部撤回」(比如「rclone 这 10 分钟删掉的全部恢复」)。整组和全部撤回会先列出「会撤回 N 项,M 项撤不了」和原因(之后又改过名、原文件夹已删除……),确认后从新到旧一条条撤。
- 撤回本身也会记进动态,标着「撤回操作」;被撤回的那条划掉、标「已撤回」。

**大量删除提醒**:WebDAV 客户端、Agent、图床密钥这类不需要你在场的来源,10 分钟内删掉 200 个以上的文件或 2 GB 以上时,会收到一条严重通知(配了推送就推到手机),点开就是动态里按这个来源和时间段筛好的列表,「全部撤回」一下回来。不是你干的,就去吊销那把应用密码或 Key。

动态保留 90 天。

## 空间

点侧栏用量条的「空间分析」:

- **总览**:各类文件(图片 / 视频 / 音频 / 文档 / 压缩包 / 代码与文本 / 其他)各占多少;回收站里还占着多少配额(可以清空);重复文件有几组、删掉多余的能省多少。
- **文件夹**:从根目录开始逐层看哪个文件夹最大,点进去往下钻。
- **大文件**、**很久没动**(一年以上没改过、100 MB 以上)、**空文件夹**、**重复文件**:勾选后「移进回收站」。重复文件默认每组留最早的那一份,其他的勾上。注意:服务器上同一份内容本来就只存一份,删重复文件省的是你的配额,不是服务器的磁盘。
- **分享与直链**:已经过期的、或 90 天没人访问的分享和直链,过期的收集链接,可以直接吊销 / 删除。

管理员在「管理」页还有一张「存储」卡片:全站各人用量加起来(逻辑)与去重后实际占的(物理)、去重省了多少、缩略图等派生文件、内容索引和动态记录各占多少。

## 订阅

侧栏「订阅」→「添加」,贴一个地址先「预览」:

- **RSS / Atom**:博客、新闻站的订阅地址;**播客**的 RSS 也是这种(认出是播客会默认选「下载附件」)。
- **GitHub 仓库**:写 `owner/repo` 或仓库网址,订的是它的 Releases;「资源文件名」写 `*.apk`、`linux-amd64` 之类只下想要的那个文件,默认不下预发布版。

订阅方式三选一:**下载附件**(播客的音频视频、GitHub 的安装包下进网盘,文件名是「日期 标题」)、**剪藏正文**(博客文章存成 Markdown,见下节)、**只记录**(列出来,想要哪条手动点)。默认存到 `/订阅/<标题>`,也可以选别的文件夹;GitHub 的资源按版本号放进子文件夹。还能设:标题里要有 / 不能有的关键词、只留最近几条(更早的自动进回收站,适合播客)、多久检查一次(默认 6 小时)、订阅时先处理最新的几条(默认 1 条,更早的标「已跳过」,想要的可以手动下)。

点一个订阅看它的条目和状态(新 / 已跳过 / 处理中 / 已完成 / 失败),单条「下载」「剪藏」「打开」;「立即检查」不等定时;「暂停」「退订」(已经下好的文件不动)。播客下好的节目直接用网盘的播放器听,接着听、连着放都有。新内容下好了会发通知(默认不推送,可在推送设置里打开),连续 3 次检查失败会提醒。

「导出 OPML」「导入 OPML」:和播客 App、RSS 阅读器互相搬订阅;导入的不补下旧内容,只接以后的新条目。不支持 YouTube、B 站这类视频网站。

## 剪藏

把网页上的文章存进网盘:正文转成 Markdown,图片一起下到旁边的「标题.assets」文件夹,广告、导航这些不要。存在 `/剪藏/年-月/` 里(右上角齿轮里可以改文件夹、是否按月分),能被内容搜索搜到,在 Typora、Obsidian 里打开也一样。

- **网页上**:侧栏「剪藏」,顶部贴链接点「剪藏」。剪过的地址再剪会问你是打开已有的还是重新剪。
- **书签栏小工具**:「剪藏」页右上角「书签栏小工具」,把「剪藏到 gopan」拖到浏览器书签栏。看到想存的文章点一下,弹出一个小窗点「剪藏」。要登录才能看的页面(付费文章、内网 wiki)服务器自己抓不到,勾「连同页面内容」,小工具会把你眼前这页的内容一起交给 gopan。
- **安卓 App**:浏览器里「分享」→「剪藏到 gopan」。
- **订阅**:订阅方式选「剪藏正文」,新文章自动剪藏。

「剪藏」页按卡片列出(标题、站点、摘要、未读的有小圆点),能筛未读、按站点;点开是阅读视图,看几秒自动标为已读,上面有「打开原网页」「在文件夹中显示」「删除」(连同图片文件夹进回收站)。少数页面认不出正文时存的是整页文字,任务里会提示。

## 收集文件

想让别人把文件传给你(收作业、收活动照片、让对方发一个大文件),在文件夹上**右键 → 收集文件**(手机上长按)。生成的链接发给别人,对方不用注册,打开就能往这个文件夹传;**看不到文件夹里已有的内容**,也看不到别人传了什么。

- **截止时间**:默认 7 天。截止前已经开始的上传允许传完,之后新的上传会被拒。
- **要求留名**:对方要先填名字;**按人分文件夹**会把每个人的文件放进以名字命名的子文件夹(自动开启留名)。名字是对方自填的。
- **上限**:单个文件、总量(默认 10 GB)、个数都可以设;总量计入你自己的空间。空间不够时对方只会看到"收件已满"。
- **密码**:可选,建好后不能改(要改就结束这条、重新开一条)。密码连续输错太多次会锁一段时间。
- 两个人传同名文件(比如都叫 `IMG_0001.jpg`)不会互相覆盖,后到的自动改名。
- 链接发进聊天,卡片上是你写的标题、说明的第一行和几天后截止;对方打开后先看到标题和说明,传完每个文件都会列在「已送达」里。
- 对方在手机上传时页面会尽量保持屏幕常亮;传完之前切走或锁屏,浏览器可能把上传掐掉,同一台手机重新打开链接、重新选同一个文件会接着传。

「我的分享」的 **收集** 标签里能看所有收集链接:收到几个、多大、几个人,新收到的标红;点进去是收件记录(谁、什么时候、什么文件、IP),点文件名直接跳到它所在的文件夹。**结束收集**立即生效,正在传的也会失败,已收到的文件不受影响。

## 回收站

- 删除的文件/文件夹进回收站,默认 **30 天后自动彻底删除**;期间可整棵还原。删除时不再先问,做完顶上有 6 秒的「撤销」;回收站里还原后点「去看看」直接到它回去的文件夹。列表里每条都显示"还剩 N 天",一天内到期的会在顶上提示。
- 回收站里的东西**仍占配额**,想立刻释放额度就手动"彻底删除"。
- 彻底删除不可恢复,没有后悔药。

## 传输助手

左侧「传输助手」是你自己一个人的会话,用来在电脑和手机之间递东西(类似微信的文件传输助手)。

- **发文本**:电脑 Enter 发送、Shift+Enter 换行;手机 Enter 换行、点按钮发送。消息里的网址可以直接点;超过 8 行的长文本折叠,点「展开」看全文。发送失败的消息标红,可以重试或移除。
- **发文件**:点回形针选文件,或者直接把文件**拖进页面**,或者 **Ctrl+V 粘贴截图**。进度就在聊天里显示,传完变成文件卡片(图片、视频直接显示缩略图),点开预览,右侧图标下载。
- **文件存哪**:所有附件都在网盘根目录的「我的设备」文件夹里。反过来也成立:用 WebDAV、rclone 或 Agent **往这个文件夹里放文件,会话里会自动多一条**。
- **复制 / 删除**:电脑上把鼠标移到消息上出现图标,手机长按。删除只删会话里的这条,文件还在网盘。右上角「复制最新文本」一键复制最后一条文字消息。
- **搜索**:右上角搜索框,按正文或文件名找。命中后点「定位」跳到它在历史里的位置,前后各带 50 条,可以继续往上下翻,底部「回到最新」回到末尾。
- **翻历史**:往上滚到顶自动加载更早的。
- **多端**:另一台设备发的消息 2 秒内出现;你在上面翻历史时底部会浮出「N 条新消息」。页面显示「离线,重连中」说明网络断了,恢复后自动续上。
- **从别的 App 分享**:Android 装成 PWA(或装了 gopan App)后,相册、浏览器等任何 App 的系统分享菜单里选 gopan:文字填进输入框,图片、视频、文件直接开始上传到传输助手。iOS 的 Safari 不支持分享到网页应用。

## 登录设备

账户菜单(侧栏最底下点自己的名字)里的「登录设备」列出账号当前的所有登录会话(一个浏览器/设备一条),能看到客户端、IP、最近活动时间与登录时间。

- **本机**标记的是你正在用的这条,不能在这里吊销——要下线请用账户菜单里的「退出登录」。
- 别的设备点"吊销",那台设备立刻需要重新登录(它手里的刷新凭证被整族作废)。
- **改密码会一次性吊销全部设备**;当前这台会无感续上,不用重新登录。
- 显示"已失效"的是已经被强制下线的会话(改密码、管理员禁用,或**检测到凭证被重放**)。最后一种最有价值:刷新凭证泄露被别人用了,整族会被吊销,你在这里能看到那个设备变成"已失效"。
- 客户端那一列是把 UA 归类成人话;认不出来时显示截断的原文,不会编一个设备名。

## 搜索

顶部搜索框输入关键词,结果页有两个标签:

- **文件名**:名字里包含关键词的文件和文件夹。
- **内容**:文件里的文字包含关键词的文件——PDF、Word / Excel / PowerPoint、OpenDocument、纯文本与代码都行。结果显示命中的那一段并标出关键词;PDF 标出第几页,点开预览直接翻到那一页。不分大小写,全角半角一样。

内容搜索的几点限制:

- 关键词**至少两个汉字或三个字母**("合同"可以,"合"不行)。
- 刚传的文件要等后台提完文字(通常几秒到几分钟,大 PDF 更久)才搜得到。
- **扫描件、图片里的字搜不到**(不做 OCR);旧版 doc / xls / ppt 只有站点开了 Office 预览、而且预览过一次之后才搜得到。
- 每个文件只收前约 35 万字;特别长的文档后半段搜不到。
- 中文 PDF 换行处的字会被连起来,所以片段里偶尔能看到两行挤在一起。

## 手机上使用

手机浏览器打开就是手机布局,不用装 App。操作与桌面一一对应,只是入口换成触屏习惯:

| 想做什么 | 怎么点 |
| --- | --- |
| 打开文件夹 / 预览文件 | **轻点**卡片 |
| 下载、分享、重命名、移动、复制、删除 | **长按**卡片,或点卡片右侧的 ⋮ |
| 多选 | 工具栏的勾选图标(或长按菜单里的「选择」),然后点卡片勾选,底部操作栏选动作 |
| 列表 / 网格切换 | 工具栏的网格图标 |
| 打开导航(文件/传输助手/分享/回收站/管理;账户菜单在导航最底下) | 左上角三道杠 |
| 预览里切换上一张/下一张 | 左右**滑动** |
| 预览里放大 | **双指捏合**;放大后拖动看图,此时不会误触切换;双击复位 |

安装到主屏(可不装,直接浏览器用也一样):

- **Android Chrome**:右上角菜单 →「安装应用」/「添加到主屏幕」。
- **iOS Safari**:底部分享 →「添加到主屏幕」。之后从桌面图标打开是独立窗口、没有地址栏。

注意:

- **不做离线缓存**。云盘离线本来也没内容可看,所以断网时打开仍是浏览器错误页。
- 上传大文件时尽量保持页面在前台:iOS 切到别的应用久了可能回收标签页,正在传的任务会断(已知问题,见 doc/14)。
- 手机上想像本地文件一样管理网盘:安卓装原生 App(系统「文件」App 里会出现 gopan);iPhone 装一个 WebDAV 客户端,按下面的 WebDAV 挂载填写。

## 安卓 App

安卓手机建议装原生 App:网页端的功能它都有,另外上传下载在后台跑(锁屏、切走、断网都能接着传),相册或文件管理器里「分享」给 gopan 直接进传输助手,系统「文件」App 里也能直接浏览、打开、保存 gopan 的文件。

- **发布页**:`https://你的域名/app`,不用登录,登录页底下也有入口。上面有功能介绍、「下载安卓 App」与「打开网页版」两个按钮,以及每个版本的更新日志;电脑上打开会显示二维码,手机扫了就到这一页。想让别人装 App,把这个地址发过去即可(发进微信、Telegram 有卡片预览)。
- **安装**:在发布页点「下载安卓 App」(或直接打开 `https://你的域名/api/app/android/latest.apk`),下载后允许浏览器「安装未知应用」。微信、QQ 里点不了下载,页面顶上会提示换到系统浏览器打开。用网页端同一套账号登录(Yophon ID 或用户名密码)。
- **升级**:「我的 → 关于 → 检查更新」;有新版本时那一项会标出来。「我的 → 关于 → 更新日志」用浏览器打开发布页的更新日志。装过 v2.6 的旧版 App 直接覆盖安装,装完重新登录一次。
- **「文件」App 里的 gopan**:登录后侧栏多一个 gopan。打开文件时先整份下到手机缓存;「另存为」进 gopan 的文件写完即进上传队列;已有文件不能原地改写。
- **后台传输**:通知栏显示进度。有些手机锁屏后会掐断后台,在系统设置里允许 gopan 后台运行、关闭电池优化即可,任务不会丢。
- 自部署的实例要用自己打包的 App(地址写在安装包里),见 doc/18。
- 没有 iOS 版:iPhone 用 Safari「添加到主屏幕」的 PWA;要原生地浏览、上传、下载,再装一个 WebDAV 客户端(见下文)。

## WebDAV 挂载(Finder / 资源管理器 / rclone / 手机 WebDAV 客户端)

把云盘挂成一块"网络磁盘"。三步:

1. 网页端账户菜单(侧栏最底下点自己的名字)→「WebDAV 应用密码」(安卓 App 里是「我的 → 应用密码(WebDAV)」)→ 输入设备名 → 生成。**密码只显示一次**,存进设备的钥匙串/配置里。
2. 客户端里填:地址 `https://你的域名/dav`,账号 = 用户名,密码 = 刚生成的应用密码(**不是登录密码,登录密码连不上**)。
3. 挂载后浏览、上传、下载、删除、移动都与网页端同一棵树,实时互通。

说明与限制:

- **每台设备生成一条**应用密码,设备丢了单独吊销那一条,别的设备不受影响;吊销即时生效。
- WebDAV 里删除同样进回收站;但**覆盖保存不进回收站**(同步工具会高频覆盖)。
- 单文件上限 5GB,更大的文件请走网页端(分片直传没有这个限制)。
- **iPhone**:系统「文件」App 的「连接服务器」只支持 SMB,连不了 WebDAV。到 App Store 装一个 WebDAV 客户端(如 Owlfiles、Readdle 的 Documents)再按上面三步填;有的客户端还能把位置加进「文件」App,以客户端的说明为准。
- rclone 示例:`rclone config` 选 webdav / vendor=other,或直接环境变量 configless 使用。

## Agent / MCP 接入

gopan 提供零本地安装的 Remote MCP,地址是 `https://你的域名/mcp`。支持 OAuth 的 MCP Host 只需要填写这个地址:首次连接会自动打开浏览器,登录 gopan 后核对权限并点“允许”;以后由客户端自动刷新授权,Agent 上传下载不需要用户打开文件选择页。

不支持 OAuth 的 Headless Agent/CI 使用 API Key:

1. 网页账户菜单(侧栏最底下点自己的名字)→「Agent 接入」→「API Key」。
2. 填名称并只勾需要的权限,创建后立即保存 `gopan_key_*`;**明文只显示一次**。
3. MCP 客户端配置 `Authorization: Bearer gopan_key_*`。

权限分五档:浏览与搜索、读取与下载、上传、新建/重命名/移动/复制、移入回收站/恢复。只做归档的 Agent 通常给“浏览 + 上传”,只做检索下载的 Agent 给“浏览 + 下载”;不要默认全选。永久删除没有 MCP 工具,Agent 最多把文件移入可恢复的回收站。

Agent 上传时可自己计算 SHA-256 争取秒传,也可以不算。未提供 SHA 时服务端会在上传后计算、去重并校验;文件字节由 Agent 通过短期预签名 URL 直传 MinIO,不塞进模型上下文。单文件下载同样返回短期 URL,文件夹/多选返回受限 ZIP 链接。

「OAuth 授权」页列出已经连接的 MCP 应用。撤销后该应用现有 Access/Refresh Token 立即失效;API Key 在另一页单独吊销,两者互不影响。完整工具参数见 `docs/MCP.md`。

## 管理(仅管理员可见)

管理员在左侧导航多一个「管理」入口(安卓 App 里是「我的 → 管理端」,功能相同):实例概览(用户数、逻辑/物理用量、任务队列)、新建用户、调配额、禁用/启用、重置密码(生成随机新密码,只显示一次)、失败任务一键重排。

几个语义:**禁用**立即踢下线该用户全部设备,其创建的分享链接连带失效,文件保留不动,解禁即恢复;**重置密码**同样会踢下线所有设备。管理员看得到每个用户的用量和配额,看不到任何人的文件内容。

首个管理员由服务器上的命令行产生(`gopan admin promote <用户名>`,见 doc/09),界面里无法自封。

## 常见问题

**上传一直卡在"校验中"?** 大文件上传完成后服务器要流式重算一遍哈希,几 GB 的文件需要一点时间,正常。

**分享链接打不开了?** 三种可能:过期、被属主吊销、地址抄错。前两种访客侧无解,找分享人重新生成。

**配额满了怎么办?** 先清回收站(那里也占额);还不够找管理员调配额。

**支持 WebDAV / 手机 App 吗?** 支持。安卓有原生 App(见上文);Finder、Windows 资源管理器、rclone 和手机上的 WebDAV 客户端使用 `/dav` + 应用密码(iPhone 自带的「文件」App 不支持 WebDAV);手机浏览器也可直接使用 Web 界面。

**Agent 一定要安装本地 bridge 吗?** 不需要。使用 Remote MCP URL 即可;上传下载由 Agent 自身的 HTTP/shell 能力访问预签名 URL。
