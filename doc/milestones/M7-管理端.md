# M7 · 管理端(计划)

> 状态:进行中。完工后本篇改写为回顾。目标见 doc/13 第四节:实例运营(账号、配额、健康)全部界面化,交付 v1.1.0。

## 交付清单

**数据与迁移**
- `00004`:users 加 `disabled_at timestamptz`(可空,禁用时间即禁用标记);down 对称。

**后端**
- CLI 子命令:`gopan admin promote <username>`——只连库改 `is_admin`,不起服务,幂等。
- service/admin.go:统一 `requireAdmin(callerID)` 入口,方法:ListUsers / CreateUser(不受注册开关限制)/ SetQuota / SetDisabled / ResetPassword(生成随机密码,仅返回一次)/ Overview(用户数、逻辑用量、物理 blob 量、任务四态计数)/ RetryFailedTasks。
- 禁用语义:`SetDisabled(true)` = 记 disabled_at + 吊销全部 refresh family;登录返回 `ACCOUNT_DISABLED`;refresh 拒绝;**分享连带失效**(shareDead 加属主禁用条件,Info/Access/Validate 三个入口全覆盖)。已发 access token 最长残留 15 分钟,与改密码的窗口一致,接受。
- auth:Login 验密通过后检查 disabled;Refresh 取用户后检查 disabled。

**GraphQL(只加不改)**
- `User.isAdmin`(me / 各 AuthPayload 带出,前端路由守卫用)。
- `AdminUser`、`AdminOverview`、`TaskCount` 类型;Query `adminUsers`、`adminOverview`;Mutation `adminCreateUser` / `adminSetQuota` / `adminSetDisabled` / `adminResetPassword` / `adminRetryFailedTasks`。
- 鉴权在 service 层 requireAdmin,resolver 只解参——与既有"resolver 不散落权限判断"一致。

**前端**
- AdminView:概览卡片(用户/存储/任务)+ 用户表格(建号、调配额、禁用/启用、重置密码,重置结果一次性展示)。
- 导航"管理"项与 `/admin` 路由:`isAdmin` 才渲染;守卫不满足直接回 /drive(不暴露路由)。

**验证**
- 集成测试:admin 全流程(建号/配额/禁用→登录拒+refresh 拒+分享失效/重置密码/非 admin 全拒 FORBIDDEN)。
- smoke `m7_admin.py`:注册→CLI promote(顺带测真实子命令)→建号→调配额→禁用→断言三处失效;入 make smoke。

## 明确不做

审计日志(单管理员无意义)、admin 代看用户文件内容(只见元数据)、demote 子命令(YAGNI)、用户删除(禁用已覆盖诉求,删除牵连 blob 归属留 v2 之后)。
