## 分享模型(service/share.go)

- **token**:10 位 base58(去 0/O/I/l),crypto/rand,≈4×10^17 种,防枚举;唯一冲突兜底重试 3 次。
- **密码**:bcrypt cost 12,空串视为无密码。**有效期**:可空,创建时校验必须是将来。
- **失效是三合一判定**(`shareDead`):吊销(revoked_at)∨ 过期(expires_at)∨ 分享根被软删。软删还原后分享自动复活;彻底删除则由 00003 的级联把分享行一起带走(没有这条迁移,PurgeSubtree 会撞外键——设计期遗漏,实现期发现)。
- shareInfo 是公开查询,只回验密前的最小信息:名称、类型、是否要密码、是否已失效。

## 访客授权:一个决定省掉半层代码

访客 JWT 的 `scope = share:{shareId}`,而 **`sub` 直接设为分享属主的 userID**。这样访客的所有查询天然复用属主视角——现有的 `owner_id = $userID` 查询条件全部原样生效,不需要为访客另写一套数据访问;权限收窄只靠一处 `Shares.Authorize`:

1. 解 scope 拿 shareID → 分享仍有效(未吊销/未过期/根未删)且 created_by 与 sub 一致;
2. 目标节点是属主的活跃节点;
3. `IsDescendant(分享根, 目标)`(复用 M1 的递归 CTE,含自身)。

子树外一律 NOT_FOUND(与属主语义一致,不暴露"存在但无权")。resolver 侧:属主路径完全不变,访客路径由 `requireNodeAccess` 统一分流;`children` 对访客禁止 parentId 为空(不许列属主根目录);`shareRoot` 返回时抹掉 parentId(分享根之上的结构不可见);访客搜索走独立的 `SearchNodesInSubtree` 递归 CTE。**访客只读**:除 verifySharePassword 外所有 Mutation 对 share scope 返回 FORBIDDEN(`httpx.UserFrom` 天然拒绝),连 requestPreview 也不放行。

verifySharePassword 按 IP 限速(同登录:6 秒回填、突发 10);无密码分享传空密码即得 token;错误码分三档:SHARE_PASSWORD_REQUIRED(没给)/ BAD_SHARE_PASSWORD(给错)/ SHARE_EXPIRED(链接死了),前端按码给不同文案。

**对设计文档的一处偏离**:SDL 原定 verifySharePassword 返回 `AuthPayload`,但它带 `User!`(用户名/配额/用量)会全数泄给访客。改为只含 accessToken 的新类型 `ShareAuth`,doc/05 已同步。

## 两个 REST 端点(httpx/share.go)

- **`/s/{token}` og 落地页**:读 embed 的 index.html,在 `<head>` 后注入 og:title(文件名,html 转义)/og:description,微信等爬虫拿到卡片,浏览器照常加载 SPA。分享无效时直出原始 SPA,由前端展示失效页。
- **`/pack?nodes=id1,id2&token=…`**:下载链接带不了 Authorization 头,access token 走查询串(15/30 分钟短命,可接受)。两阶段:**Collect** 先逐根鉴权(属主/访客同走 Shares.Authorize)+ 递归遍历子树算清单和总量——所有错误在写响应头之前暴露,能正确回 401/403/404/410/413;超 2GB 拒绝。**Stream** 再流式写 zip:`archive/zip` + `Method: Store`(只打包不压缩,CPU 便宜、可顺序流出),文件从 MinIO `Open` 直接 `io.Copy` 进 zip entry,空目录也建目录项,多选根重名自动 `(1)` 解冲突。这是全项目唯一经过 Go 的文件字节流。

## 前端(三个新组件 + 访客改造)

- **ShareDialog**:有效期单选(1/7/30 天/永久)+ 密码开关;创建成功切换为结果态,复制链接或"链接+密码"一起复制。
- **SharesView**:列表展示节点名/密码锁标/创建时间/有效期(过期红字),复制链接、Popconfirm 取消分享。
- **ShareVisitorView**(`/s/:token`,公开路由,守卫直接放行):
  - 状态流:shareInfo → 失效页 / 验密卡片 / 内容态;无密码分享自动以空密码领 token。
  - 访客凭证存 **sessionStorage** 按 token 隔离;任何请求遇 UNAUTHENTICATED/SHARE_EXPIRED(30 分钟过期或属主中途吊销)→ 清凭证弹回验密态并刷新 shareInfo。
  - **面包屑用导航栈而非 parentId 回溯**——分享根之上对访客不可见,沿 parentId 爬会 403;进入文件夹压栈、点面包屑裁栈。
  - 分享根是文件 → 单文件卡片(预览/下载);是文件夹 → 列表浏览 + "打包下载全部"。
- **client.ts 加 `guestRequest`**:带指定访客 token、不走用户登录态、不做 401 刷新的第三条请求通道。
- **PreviewModal 加 `guestToken` prop**:传入则全部请求走访客通道;访客不自动触发 Office 转换(只读白名单),没有现成产物时引导下载——属主转过一次的文档,访客直接看(派生物按 hash 全站共享,M3 的红利)。
- DriveView:工具栏"分享"按钮(单选)、右键菜单放开文件夹(打包下载/分享)、文件夹下载走 `/pack`。

## 踩坑记录

1. **shares 外键无级联**(设计期遗漏):彻底删除已分享的节点直接撞 `shares_node_id_fkey`。迁移 00003 改 `ON DELETE CASCADE`,集成测试专门覆盖了"Purge 被分享节点 → 分享随之消失"。
2. **AuthPayload 泄配额**:见上,改 ShareAuth。教训:给"另一类主体"发凭证时,返回结构要按最小知情重新审一遍,不能顺手复用。
3. **el-dialog 具名插槽嵌在条件 template 里不生效**:`<template #footer>` 必须是组件直接子级,放进 `<template v-if>` 后 vue-tsc 报一串"未使用"才暴露。重构为单个 footer 内部 v-if 分支。
4. **m2smoke 假阳性回归**:M4 完成后回归 M2 smoke 失败,查明是脚本假设服务以 5MiB 分片启动(12MB=3 片),而当次用默认 16MiB——环境假设写死在断言里,非代码回归。按原环境重跑即绿。
