## 回收站自动清理

worker 加第三个周期任务(与 session-cleanup / blob-gc 同模式,每小时)。清理逻辑放在 `Nodes.PurgeExpiredTrash(ttl)` 而不是 worker 里——worker 只做调度,业务(含退配额、减引用的事务)复用既有 `Purge`,集成测试直接测 service 不用摸 worker。查询只判**顶层**的 `deleted_at`:整树软删是同一时刻,还原过的子树不在回收站,顶层过期即整树过期。每轮上限 500 根,防上线首跑清历史存量时单事务过大。

## copyNodes:内容寻址的红利兑现

文件复制 = 新 node 指向同一 blob + `ref_count+1` + 配额照扣,MinIO 一个字节不动。实现是三段式:

1. **快照收集**:深度优先遍历子树(复用 /pack 的 `ListActiveChildrenLite`,给它补了 `blob_id` 字段),产出"父在前"的有序清单;边收集边累计逻辑大小,超 1 万节点直接拒(单事务上限)。
2. **预检**:配额(`used + total > quota` → QUOTA_EXCEEDED)、目标不在任一源的子树内(复用 `IsDescendant`,否则递归复制自己无限膨胀,错误码 CYCLIC_COPY)、根名解冲突。
3. **单事务落库**:按序建新 node(清单下标 → 新 uuid 的映射解析父子关系),逐个 `IncrementBlobRef`,配额一次加总。

多选复制有个细节:两个不同目录下的同名文件复制到同一目标,`cleanName` 查库判重时第一个还没落库,两个都会拿到原名撞唯一索引。解法是 `cleanNameTaken`——原函数加一个本批已用名的本地 set,查库之前先查它。

## changePassword

doc/06 早就写好了语义:"改密码 = 吊销该用户全部 family"。实现:bcrypt 验旧 → 新密码同注册规则 → 更新 hash → `RevokeAllUserFamilies`(新查询,按 user_id 吊销全部 refresh)→ **当场重新 issuePair**。效果:其它设备全部掉线,当前会话拿到新 pair 无感续命(前端 `setAuth` 接住)。按 IP 限速复用 Auth 的令牌桶。

## 部署工件

- **Dockerfile** 三阶段:node 装依赖构建前端 → dist 拷进 `cmd/gopan/dist` 后 `CGO_ENABLED=0` 编译 → debian-slim 运行时。ffmpeg 用 apt 装出来 733MB(依赖树太重),换 `mwader/static-ffmpeg` 静态双二进制降到 **491MB**——仍超计划的 300MB 目标,再压就得砍 ffprobe 改代码,单机自部署不值得,如实记录。非 root(uid 10001)运行,HEALTHCHECK 内置。
- **compose.prod**:backend 网络 `internal: true`(postgres/minio/gotenberg/gopan 全部不通公网,gotenberg 处理用户文件、无出网是 doc/06 的防 SSRF 要求),只有 Caddy 暴露 80/443;JWT 走 secrets 文件;healthcheck 全覆盖,gopan `depends_on: service_healthy`。
- **Caddyfile**:预签名 URL 是 `https://{域名}/{bucket}/{key}?X-Amz-…`(minio-go 对自定义域用 path-style,bucket 就在路径里),所以按 `/gopan/*` 转 MinIO,**不剥前缀、透传 Host**——V4 签名把两样都签进去了。
- **backup.sh** + cron:`pg_dump -Fc` + minio 卷 tar,保留 7 天;恢复步骤在 doc/09,含"两份备份非同一瞬间快照"的缝隙说明。

## 踩坑记录

1. **生产必炸 bug,容器验证抓到**:镜像跑 m5smoke,initUpload 报 INTERNAL,日志里是 `Get "http://127.0.0.1:9000/gopan/?location=": connection refused`——minio-go 签名前会向 **public** endpoint 发 GetBucketLocation 探测。dev 里 public=internal 从没暴露;生产里 public 是公网域名、gopan 在无出网内网,必炸。修复:显式 `S3_REGION`(默认 us-east-1),minio-go 有 region 就跳过探测。同时把 `S3_PUBLIC_USE_SSL` 从内部开关拆出来(内网 http、公网经反代 https)。**教训:双 client 的每一次网络行为都要问一句"这个请求打到哪个地址"。**
2. **pnpm v10 拦截依赖构建脚本**:容器里 `pnpm install --frozen-lockfile` 因 esbuild 的 postinstall 被默认策略拒绝而失败(本机老配置无感)。package.json 补 `pnpm.onlyBuiltDependencies` 白名单 + `packageManager` 钉版本。
3. **管道又吞退出码**:`docker build | tail` 让第一次失败的构建看着像成功(M1 的老教训重演)。验证类命令一律不接管道,输出重定向到文件。
4. **smoke 自身的假阳性**:CYCLIC_COPY 断言最初拿的是**副本**的子目录当目标——那不在源子树里,当然不报环。测越界/成环时,目标必须取自原树。
