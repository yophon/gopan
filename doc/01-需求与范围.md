# 01 · 需求与范围

gopan:自部署云盘。Go 后端 + Vue 前端,单二进制交付(前端 embed 进后端),依赖组件只有 Postgres、MinIO、Gotenberg。

## v1 功能清单

**账户**
- 注册(可配置关闭)、登录、登出
- 双 token:access JWT(15 分钟)+ refresh token(14 天,旋转,可吊销)
- 每用户存储配额

**文件管理**
- 目录树:建文件夹、重命名、移动、复制引用
- 列表:排序(名称/大小/时间)、游标分页、按文件名搜索
- 回收站:软删除、还原、彻底删除、30 天自动清理

**上传**
- 秒传:客户端先报 SHA-256,命中即建引用
- 分片上传:16MB 分片,预签名 URL 直传 MinIO,3~4 片并发
- 断点续传:会话可查已传分片,刷新页面后接着传
- 全局上传队列:暂停、取消、失败重试

**下载**
- 预签名 GET 直连 MinIO,支持 Range
- 文件夹打包下载(v1 限制总大小,流式 zip)

**预览**
- 图片:缩略图(256px)+ 大图(2048px)+ 原图
- PDF:原文件直出,前端 PDF.js 渲染
- Office(docx/xlsx/pptx 等):异步转 PDF 后按 PDF 预览
- 音视频:mp4/mp3 等浏览器原生格式直接流式播放;抽封面和时长
- 文本/代码:小于 1MB 直接取原文显示

**分享**
- 文件或文件夹皆可分享:短链 token、可选密码、可选有效期
- 访客凭 token(+密码)获得子树范围的只读访问:浏览、预览、下载
- 分享管理:列表、吊销

## v1 明确不做

- 在线编辑(Office 协同、文本编辑器)
- 端到端加密、客户端加密
- 视频转码(HLS)、非浏览器格式的播放
- 多机部署、副本、CDN
- 全文内容搜索(只搜文件名)
- WebDAV(接口预留,v2 做)
- 移动端 App(Web 自适应即可)

## 非功能要求

- 上传下载字节流不经过 Go 进程(预签名直传/直取),Go 只做编排
- 所有代码 CGO_ENABLED=0,交叉编译和静态部署不破功
- 单机 4C8G 支撑 50 并发用户、单文件 20GB、总量 2TB 不出结构性问题
- pprof 常驻内网端口,线上问题可剖析

## 术语

| 词 | 含义 |
|---|---|
| node | 目录树节点,文件或文件夹,属于某个用户 |
| blob | 按 SHA-256 去重的物理文件,全局共享,引用计数 |
| derivative | 由 blob 派生的预览产物(缩略图/PDF/封面),同样按源 hash 去重 |
| upload session | 一次分片上传的服务端记录,断点续传的依据 |
| share | 分享:token → 某个 node 子树的只读授权 |
