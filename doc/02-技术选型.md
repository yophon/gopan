# 02 · 技术选型

原则:单二进制、少依赖、标准库优先、类型从数据库一路通到前端组件不断链。

## 后端

| 层 | 选择 | 理由 |
|---|---|---|
| 语言 | Go 1.26,CGO_ENABLED=0 | 静态二进制,交叉编译白送 |
| Web API | gqlgen(GraphQL) | schema-first + 代码生成;浏览器控制面统一走 `/query` |
| Agent API | modelcontextprotocol/go-sdk | 官方 Go SDK 实现 Streamable HTTP `/mcp`,工具 schema 从 Go 类型推导 |
| HTTP | 标准库 net/http | GraphQL、MCP、OAuth、WebDAV、健康检查与打包下载共用一个标准库 mux |
| 元数据库 | PostgreSQL 16+ | 事务(移动/引用计数)、递归 CTE(子树)、pg_trgm(文件名搜索) |
| DB 访问 | pgx + sqlc + goose | SQL 生成类型安全代码,无 ORM 魔法;goose 管迁移 |
| 对象存储 | MinIO(S3 协议)+ minio-go v7 | 分片上传用 S3 Multipart API,预签名直传;代码只依赖 S3 协议,可换任何兼容存储 |
| 认证 | JWT + 不透明 refresh + OAuth 2.1/PKCE + 哈希 API Key/应用密码 | 不同入口使用独立凭据,权限实时查库;细节见 06 |
| 文档转换 | Gotenberg(容器) | LibreOffice + Chromium 的无状态 HTTP 服务,office → PDF 一个 POST |
| 音视频 | ffmpeg / ffprobe(exec 调用) | 抽封面、取时长;不转码 |
| 图片处理 | disintegration/imaging | 纯 Go,不碰 cgo |
| 异步任务 | 进程内 worker pool + tasks 表持久化状态 | 单机不上消息队列;重启后扫表恢复未完成任务 |
| 日志 | log/slog(JSON 到 stdout) | 容器采集友好 |
| 配置 | flag + 环境变量 | 十几个配置项,不上配置框架 |

## 前端

| 层 | 选择 | 理由 |
|---|---|---|
| 框架 | Vue 3 + `<script setup>` + TypeScript | Composition API 唯一写法 |
| 构建 | Vite,产物 //go:embed 进后端 | 整个云盘 = 一个二进制;开发期 Vite proxy |
| 路由/状态 | Vue Router + Pinia | 上传队列、登录态、多选态放 Pinia;OAuth consent 是独立路由 |
| 数据层 | @tanstack/vue-query + graphql-request + GraphQL Code Generator | key 失效模型直觉;codegen 保证 schema 改动前端立刻类型报错 |
| UI | Element Plus | 表格/树/右键菜单/对话框齐全,中文资料多 |
| 工具 | VueUse | 拖拽、快捷键、剪贴板 |
| 大列表 | @tanstack/vue-virtual | 大目录必虚拟滚动 |
| 图片预览 | v-viewer | 缩放旋转翻页 |
| PDF | pdfjs-dist | 后端把 office 统一转成 PDF,前端只处理一种文档格式 |
| 音视频 | 原生 video/audio 标签(可选 Artplayer 皮肤) | Range 由 MinIO 承担 |
| Hash | hash-wasm,跑 Web Worker | 秒传算 SHA-256 不卡主线程 |

## 明确不用与理由

| 不用 | 理由 |
|---|---|
| gin/echo | GraphQL 场景下框架路由无用武之地;handler 签名与标准库割裂 |
| GORM | 引用计数、子树 CTE 这类 SQL 用 ORM 反而绕;sqlc 已给类型安全 |
| Apollo/urql 规范化缓存 | 概念重、调试难;云盘交互全是「mutation 后刷新目录」,key 失效模型足够 |
| Nuxt | 全站在登录墙后,SSR 无收益;分享落地页的 og 标签由 Go 模板直出(见 03) |
| Redis | session 在 Postgres、任务在进程内、无热点缓存需求;v1 每少一个组件赚一个 |
| tus / Uppy | 秒传+断点协议与后端强耦合,自研上传器几百行更干净 |
| axios | 数据层被 vue-query 覆盖;直传 MinIO 用原生 fetch + AbortController |

## 运行组件清单

gopan(Go 二进制,内嵌前端和 Remote MCP/OAuth server)、PostgreSQL、MinIO、Gotenberg。MCP 不增加进程或容器,Gotenberg 可选;docker compose 一把起,见 08。
