# 12 · 产品说明

一页说清 gopan 是什么、给谁用、能做什么、明确不做什么。怎么用见 doc/11,怎么部署见 doc/09。

## 定位

**给个人和小团队的自部署云盘**:数据放在自己的服务器上,一个 Go 二进制加 Postgres、MinIO 就能跑,2 核 2G 的廉价 VPS 即可承载。核心取向是**轻**——组件少、内存省、维护成本接近零,与 Nextcloud 那类"自部署全家桶"不是一个物种。

适合:有一台 VPS、想要"自己的网盘"存取和分享文件的人;希望让 Agent 在明确授权下代为整理、上传、下载云盘的人;不想为一个网盘常驻一套 PHP + Redis + 十个容器的人。

不适合:需要多人协同编辑、端到端加密、多人权限体系的团队——这些明确不在范围内(见能力边界)。

## 能力边界(明确不做)

| 不做 | 说明 |
|---|---|
| 多人协同编辑 | 文本文件能直接改(doc/25),Office 文件不在线编辑,也不做多人同时编辑 |
| 端到端加密 | 服务端可见明文(否则秒传、预览、打包全部失效);传输层 TLS,存储桶全私有 |
| 视频转码 | 网页放不了的 mkv / avi 等只换封装、不重新编码画面(doc/31);画面编码浏览器不认的提示下载,或用安卓 App、桌面端的播放器看 |
| 字幕编辑、在线搜字幕 | 只挂同文件夹里的外挂字幕;ASS 只保留文字和时间,样式与特效丢掉 |
| 邮件通知、手机厂商推送 | 推送走 Webhook / ntfy / Bark / Telegram;安卓 App 不接 Google 推送,系统通知栏提醒靠每 15 分钟检查一次 |
| 图片处理、自定义域名 | 图床不压缩、不加水印、不转格式(只提供已有的 256 / 2048 缩略图);直链只在本站域名下 |
| OCR | 扫描件、图片里的字不识别;内容搜索只搜文件本身带的文字 |
| 彻底删除后找回 | 回收站清空、彻底删除的文件找不回来;同名覆盖留历史版本(doc/24),动态里的撤回管移动、改名、删除(进回收站)与新建 |
| 视频站订阅 | 订阅不支持 YouTube、B 站等(要 yt-dlp);只认 RSS / Atom 与 GitHub Releases |
| 整页快照 | 剪藏只存正文(Markdown + 图片),不存原样网页、截图或 PDF;不编辑 Markdown |
| BT / 磁力、网盘分享页 | 离线下载只下 http / https 直链;需要登录、网盘分享页拿不到真实地址 |
| 加密压缩包、分卷压缩 | 加密的只能看目录(文件名没加密时),不能预览和解压;分卷包不支持 |
| 多机/集群 | 单机产品;数据库与对象存储可外迁托管服务 |
| iOS App | 只有安卓原生 App(v3.0);iPhone 用浏览器(可添加到主屏)或 WebDAV 客户端 |

## 数据与安全(用户视角)

- **数据在哪**:元数据在你的 Postgres,文件在你的 MinIO(或任何 S3 兼容存储),都在你自己的机器上。除了你主动发起的离线下载、你自己配的推送渠道,gopan 不与任何外部服务通信。
- **直链是公开的**:拿到地址的任何人都能访问,所以每次访问都记账(IP、客户端、来源站点),有流量上限和异常提醒,随时可暂停、吊销。HTML 永远只能下载、SVG 在沙箱里显示,不会借你的域名执行脚本。
- **谁能看到文件**:只有属主,以及属主明确分享出去的子树(访客只读、可设密码和有效期、可吊销)。存储桶全私有,所有访问走短时效签名 URL(下载 15 分钟)。
- **密码怎么存**:用户密码与分享密码均为 bcrypt 哈希,不存明文;登录凭据短寿命+自动轮换,凭据被盗用会触发全端强制下线。
- **Agent 凭据怎么存**:API Key、OAuth code/access/refresh 与 WebDAV 应用密码都是高熵随机串,数据库只存 SHA-256。API Key 明文只显示一次;OAuth 授权和 Key 都可独立吊销。
- **去重的含义**:相同内容全站只存一份物理文件(按 SHA-256),配额按每人逻辑用量各记各的。这意味着服务器管理员理论上可判断"某个已知文件是否有人存过"——自部署场景下管理员即属主,通常不构成问题。
- **删除的语义**:回收站 30 天后、或手动彻底删除后,当无任何用户再引用该内容时,物理文件在 24 小时宽限期后从存储中真正清除。

## 规格与限制

| 项 | 值 |
|---|---|
| 设计目标 | 单机 4C8G:50 并发用户、单文件 20GB、总量 2TB |
| 实测下限 | 2 核 2G VPS(精简档,常驻 ~350MB)稳定运行 |
| 分片大小 | 16MB(可配),单次拖拽上限 1000 文件 |
| 打包下载 | 单次 2GB |
| 文本预览 | ≤1MB |
| 访客授权 | 30 分钟,自动重验 |
| MCP OAuth | Access 1 小时;Refresh 30 天并轮换;授权码 5 分钟一次性 |
| MCP Agent 上传 | 单 PUT 或 multipart 直传;SHA-256 可选;活跃会话每用户 20 个 |
| 回收站保留 | 30 天 |
| 离线下载 | 一次 10 条链接,每人排队 + 进行中 10 个,单文件 20GB(可配) |
| 压缩包 | 单个文件预览 ≤ 100MB;一次解压 ≤ 2 万个文件;目录最多列 10 万条;解码字典 ≤ 64MB |
| 直链 | 每条每天 5 GiB、全站每月 200 GiB(可配,超了暂停并提醒);全站同时 16 路;每 IP 每分钟 120 次;访问明细保留 30 天,统计 90 天 |
| 图床 | 只收图片,单张 ≤ 20 MiB(可配);每把密钥每分钟 30 张 |
| 通知 | 保留 90 天、每人最多 1000 条;每个推送渠道每小时最多 20 条,失败重试 3 次 |
| 字幕与进度 | 字幕文件 ≤ 2 MB;进度只记 5 分钟以上的音视频与 3 页以上的 PDF,每人留最近 500 条 |
| 动态 | 保留 90 天;一次撤回最多 1000 条;大量删除提醒:同一个 WebDAV / Agent / 图床凭据 10 分钟内 ≥ 200 个文件或 ≥ 2 GiB,每小时一次 |
| 订阅 | 每人 100 个;默认 6 小时检查一次(1 小时到 7 天);每个订阅留最近 300 个条目;订阅文档 ≤ 5 MB |
| 剪藏与 Markdown | 网页 ≤ 5 MB;每篇最多 50 张图、每张 ≤ 10 MB、合计 ≤ 50 MB;Markdown 渲染 ≤ 2 MB |

## 与同类的差异

| | gopan | Nextcloud / Seafile 类 |
|---|---|---|
| 交付 | 单二进制 + 2 个依赖容器 | PHP/多组件全家桶 |
| 最低配置 | 2G 内存舒适运行 | 4G 起步,越用越重 |
| 字节流路径 | 浏览器/Agent 直连对象存储;WebDAV/zip 显式中转 | 多数经应用中转 |
| 功能面 | 存储/预览/分享/WebDAV/Agent 工具,刻意克制 | 日历、办公、插件生态 |
| 适用 | 个人、小圈子 | 组织级协作 |

一句话:功能上是它们的子集,资源占用和运维成本上是另一个量级。要的就是这个子集的话,gopan 轻得多。
