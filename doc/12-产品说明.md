# 12 · 产品说明

一页说清 gopan 是什么、给谁用、能做什么、明确不做什么。怎么用见 doc/11,怎么部署见 doc/09。

## 定位

**给个人和小团队的自部署云盘**:数据放在自己的服务器上,一个 Go 二进制加 Postgres、MinIO 就能跑,2 核 2G 的廉价 VPS 即可承载。核心取向是**轻**——组件少、内存省、维护成本接近零,与 Nextcloud 那类"自部署全家桶"不是一个物种。

适合:有一台 VPS、想要"自己的网盘"存取和分享文件的人;不想为一个网盘常驻一套 PHP + Redis + 十个容器的人。

不适合:需要在线协作编辑、端到端加密、多人权限体系的团队——这些明确不在范围内(见能力边界)。

## 功能总览

| 域 | 能力 |
|---|---|
| 传输 | 分片直传(浏览器直连对象存储,16MB/片并发)、秒传(内容级去重)、断点续传(断网/关页面后接着传)、上传队列(暂停/恢复/取消/自动重试) |
| 文件管理 | 目录树、重命名/移动/复制/多选批量、按名搜索、排序、同名自动改名、文件夹体积统计 |
| 预览 | 图片(缩略图+大图缩放)、视频/音频流式播放、PDF、文本/代码、Office 转 PDF 预览(可选组件) |
| 下载 | 单文件直连(支持 Range)、文件夹/多选流式 zip 打包(单次 2GB) |
| 分享 | 文件与文件夹、可选密码、可选有效期、访客只读子树访问、社交卡片预览、随时吊销即时生效 |
| 回收站 | 软删除、还原、30 天自动清理 |
| 账户 | 注册开关、每用户配额、改密码全端下线 |
| 管理端 | 建号/禁用(分享连带失效)/调配额/重置密码、实例概览、失败任务重排;首个管理员 CLI 自举 |
| WebDAV | Finder/资源管理器/rclone/手机文件 App 挂载;应用密码(每设备一条可单独吊销);单文件 5GB |
| 运维侧 | 健康检查、Prometheus 指标、结构化日志、每日备份脚本(保留期/水位预检/可选异地) |

## 能力边界(明确不做)

| 不做 | 说明 |
|---|---|
| 在线编辑、协同 | 只做存储、预览、分享;要协作用专门的工具 |
| 端到端加密 | 服务端可见明文(否则秒传、预览、打包全部失效);传输层 TLS,存储桶全私有 |
| 视频转码 | 浏览器原生格式直接播,其余下载后本地看 |
| 全文搜索 | 只搜文件名,不索引内容 |
| 多机/集群 | 单机产品;数据库与对象存储可外迁托管服务 |
| 移动 App | Web 自适应,手机浏览器可用;文件类 App 走 WebDAV 挂载 |

## 数据与安全(用户视角)

- **数据在哪**:元数据在你的 Postgres,文件在你的 MinIO(或任何 S3 兼容存储),都在你自己的机器上。gopan 不与任何外部服务通信。
- **谁能看到文件**:只有属主,以及属主明确分享出去的子树(访客只读、可设密码和有效期、可吊销)。存储桶全私有,所有访问走短时效签名 URL(下载 15 分钟)。
- **密码怎么存**:用户密码与分享密码均为 bcrypt 哈希,不存明文;登录凭据短寿命+自动轮换,凭据被盗用会触发全端强制下线。
- **去重的含义**:相同内容全站只存一份物理文件(按 SHA-256),配额按每人逻辑用量各记各的。这意味着服务器管理员理论上可判断"某个已知文件是否有人存过"——自部署场景下管理员即属主,通常不构成问题。
- **删除的语义**:回收站 30 天后、或手动彻底删除后,当无任何用户再引用该内容时,物理文件在 24 小时宽限期后从存储中真正清除。

## 规格与限制

| 项 | 值 |
|---|---|
| 设计目标 | 单机 4C8G:50 并发用户、单文件 20GB、总量 2TB |
| 实测下限 | 2 核 2G VPS(精简档,常驻 ~350MB)稳定运行 |
| 分片大小 | 16MB(可配),单次拖拽上限 1000 文件 |
| 打包下载 | 单次 2GB |
| 文本预览 | ≤1MB |
| 访客授权 | 30 分钟,自动重验 |
| 回收站保留 | 30 天 |

## 与同类的差异

| | gopan | Nextcloud / Seafile 类 |
|---|---|---|
| 交付 | 单二进制 + 2 个依赖容器 | PHP/多组件全家桶 |
| 最低配置 | 2G 内存舒适运行 | 4G 起步,越用越重 |
| 字节流路径 | 浏览器直连对象存储,应用进程零字节转发 | 多数经应用中转 |
| 功能面 | 存储/预览/分享,刻意克制 | 日历、办公、插件生态 |
| 适用 | 个人、小圈子 | 组织级协作 |

一句话:功能上是它们的子集,资源占用和运维成本上是另一个量级。要的就是这个子集的话,gopan 轻得多。

## 版本与路线

当前 **v2.0.0**(2026-07):v1 存储/预览/分享 + v2 管理端/规模/WebDAV。后续以实际需求驱动的日常迭代为主(预览预加载、PWA、total 计数优化等候选),不做时间表承诺。
